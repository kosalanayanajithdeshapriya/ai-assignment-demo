Step 1 — Copy These Prompts Into Real ChatGPT / Claude

Open chat.openai.com and claude.ai in separate tabs. For each task, click "Copy Prompt", paste it into both tools, and copy back whatever Python function they give you.

Step 2 — Paste the AI-Generated Code Back Here

Keep the exact function name shown in the prompt. Paste the full function body (only the def ... block) for each tool/task combination.

⚠ Because copy-paste can strip real spaces/indentation, the prompts above ask the AI to mark indentation with literal > characters instead of spaces (e.g. > return True = one level deep). This app converts those markers back into real Python indentation automatically, so the reconstruction is exact even if whitespace gets stripped in transit. If a tool ignores this and replies with normal spaced code, that's fine too — plain, correctly-indented code still works as-is.
